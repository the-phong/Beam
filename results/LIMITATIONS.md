# Limits on interpretation

- **Topology and source:** Four Comet validators shared one physical host and its CPU, disk and scheduler. Published sends originated at validator-0 loopback RPC. Multi-host effects, independent physical failure domains, P2P-origin injection and Internet propagation were not tested.
- **Observation:** The nominal 100-ms block scanner reports send-to-first-all-four inclusion-observation upper bounds. It does not timestamp exact commit or finality. The historical 3-second timely endpoint is ceiling-limited when all fixed transactions are timely.
- **Resource attribution:** Process CPU includes runtime/GC and other work. X16 stage thread CPU is measured with a probe that increased app CPU; native unperturbed crypto-stage CPU and exact relay/commit shares are null. X07 queue-path intervals are probe-conditioned. Socket wait is not the whole transaction queue; overlapping mempool, relay and consensus paths have no single additive residence scalar.
- **Load and precision:** Runs obeyed the applicable 25-tx/s, 65,536-B/s, 16-outstanding and 60-second safety bounds. No knee was observed; 25 tx/s is a cap, not capacity. Short eventual goodput is not sustainable steady-state throughput. p99 inference is unavailable or insufficient in several historical cases.
- **Causal comparison:** CP matches H wire size but parser/path details remain; P is not size-matched. Valid B traffic enters downstream work and invalid I traffic is rejected, so I−B is a workload replacement effect rather than pure ML verification CPU. Shared-host scheduling and scanner phase can contribute to latency contrasts.
- **Data access:** Public derived values and hashes can be audited, but complete raw rederivation requires private immutable sessions and the original locked source commit from this Git history. Excluded/interrupted sessions remain private and are not pooled. A fresh clone cannot claim full raw reproducibility without these inputs.
- **Research scope:** No sustained legitimate-service degradation event, DoS, cross-host performance or ML detector benefit was established. RQ2 early degradation remains NOT ESTABLISHED; RQ3 remains NOT_RUN. Negative results remain part of the record.
